# Nexlify: IPTV Player لشاشات LG (webOS) وسامسونج (Tizen)

تطبيق مجاني لتشغيل اشتراك Xtream على شاشات LG وسامسونج، بالعربي والإنجليزي.

- **شاشة رئيسية** زي Netflix: صورة كبيرة للحاجة اللي واقف عليها، وتحتها صفوف "كمّل المشاهدة" و"القنوات الأخيرة" و"المفضلة" و"أحدث الأفلام والمسلسلات".
- **قنوات** مع البرنامج اللي شغال دلوقتي واللي بعده، وقسم للقنوات اللي اتفرجت عليها مؤخراً.
- **أفلام** فيها صفحة تفاصيل (القصة، التقييم، المدة، الممثلين)، وتقدر تكمّل من حيث وقفت.
- **مسلسلات** بالمواسم والحلقات، والحلقة اللي بعدها بتشتغل لوحدها.
- **المفضلة والبحث**، والتحكم كامل بالريموت، ومؤشر الـ Magic Remote بيشتغل كمان. تقدر تضغط على شريط التشغيل وتنط لأي وقت.
- **بيانات الاشتراك** بتتكتب على الشاشة مرة واحدة، ومابتتبعتش لأي حد غير سيرفر الاشتراك.
- **أكتر من اشتراك:** **الإعدادات ← الاشتراكات**. تضيف أي عدد اشتراكات وكل واحد باسمه، وتبدّل بينهم، وتعدّل وتمسح. كل اشتراك ليه مفضلته وأماكن المشاهدة بتاعته لوحده.
- **كل الاختيارات بتفتح قايمة** تختار منها، وتسجيل الخروج والحذف بيسألوك "أيوه / لأ" الأول.
- **3 أشكال تختار منهم** من **الإعدادات ← الشكل**: Aurora، وCinema (القايمة شريط فوق)، وPulse. كلهم فيهم نفس المميزات بالظبط.
- **بيفتح على نفس المكان:** لو التطبيق اتقفل أو اتحدّث، بيرجع على نفس الشاشة والقناة أو الفيلم أو الحلقة، ومن نفس الثانية.
- **المشغّل:** فيه زراير كبيرة (اللي فاتت، رجوع 10، تشغيل، تقديم 10، الجاية) تتنقل لها بـ ⬇️، وكارت "الحلقة الجاية" قبل آخر الحلقة.
- **اللغة** بتتغير من **الإعدادات ← اللغة**، أو من زرار English/العربية في شاشة الدخول.

## أولاً: تجهيز الشاشة (مرة واحدة)

1. اعمل حساب مجاني على https://webostv.developer.lge.com (Sign In ← Create Account).
2. على الشاشة: افتح **LG Content Store**، ودوّر على **Developer Mode** وثبّته.
3. افتح تطبيق Developer Mode، وادخل بحساب LG Developer.
4. فعّل **Dev Mode Status**، والشاشة هتعمل ريستارت.
5. افتح Developer Mode تاني، وفعّل **Key Server**.
6. اكتب عندك **الـ IP** و**الـ Passphrase** اللي ظاهرين في التطبيق.

## ثانياً: تجهيز الكمبيوتر (ويندوز، مرة واحدة)

1. نزّل **Node.js LTS** من https://nodejs.org وثبّته.
2. افتح **Command Prompt** واكتب:
   ```
   npm install -g @webos-tools/cli
   ```
3. ضيف الشاشة باسم `tv`. حط الـ IP بتاع شاشتك مكان `192.168.1.50`:
   ```
   ares-setup-device -a tv -i "host=192.168.1.50" -i "port=9922" -i "username=prisoner"
   ```
4. اربط الكمبيوتر بالشاشة، ولما يسألك اكتب الـ Passphrase:
   ```
   ares-novacom --device tv --getkey
   ```
5. اتأكد إن الربط شغال:
   ```
   ares-device --device tv --system-info
   ```

> الكمبيوتر والشاشة لازم يكونوا على نفس الواي فاي.

## ثالثاً: تثبيت التطبيق

من فولدر المشروع، دوس دبل كليك على `scripts\install.bat`، أو شغّله من Command Prompt:
```
scripts\install.bat
```
السكريبت بيعمل الآتي:
- بيحمّل مكتبة تشغيل البث (mpegts.js).
- بيعمل باكدج للتطبيق ويثبّته على الشاشة ويفتحه.

بعد كده هتلاقي **IPTV Player** في قايمة التطبيقات على الشاشة.

## رابعاً: التجديد الأوتوماتيك لـ Developer Mode

وضع المطوّر بيخلص بعد 50 ساعة، ولما يخلص الشاشة بتمسح التطبيق. ملف GitHub في المشروع بيجدده كل يوم لوحده.

1. ارفع المشروع على GitHub كـ repo **Private**.
   - الـ repo لازم يكون Private، لأن GitHub بيوقف المهام المجدولة في الـ repos العامة لو فضلت 60 يوم من غير أي تعديل.
2. هات الـ token من الشاشة بالأمر ده:
   ```
   scripts\get-devmode-token.bat
   ```
   هيطبعلك نص طويل، وده هو الـ token.
3. على GitHub افتح الـ repo، وروح على **Settings ← Secrets and variables ← Actions ← New repository secret**:
   - Name: `LG_DEVMODE_TOKEN`
   - Secret: الـ token اللي طلع في الخطوة اللي فاتت
4. روح على تبويب **Actions**، واختار **Extend LG Developer Mode**، ودوس **Run workflow**.
5. افتح تطبيق Developer Mode على الشاشة، واتأكد إن العداد رجع لحوالي 50 ساعة.

> لو التشغيل فشل (هيوصلك إيميل من GitHub)، فغالباً الـ token اتغيّر. ده بيحصل لو قفلت وضع المطوّر وفتحته تاني. الحل إنك تعيد الخطوتين 2 و3.
>
> ولو الشاشة مسحت التطبيق في أي وقت، شغّل `scripts\install.bat` تاني وهيرجع.

## تثبيت التطبيق على شاشة LG تانية (شاشات العيلة)

**مرة واحدة على الكمبيوتر:** ثبّت **GitHub CLI** وسجّل دخول. ده بيخلي السكريبت يحط الـ token في GitHub لوحده.
```
winget install --id GitHub.cli
```
اقفل الـ Terminal وافتحه تاني، وبعدين:
```
gh auth login
```
اختار **GitHub.com**، وبعدين **HTTPS**، وبعدين **Login with a web browser**.

**لكل شاشة جديدة:**
1. على الشاشة: ثبّت **Developer Mode** من LG Content Store، وادخل بنفس حساب المطوّر بتاعك. فعّل **Dev Mode Status**، وبعد الريستارت فعّل **Key Server**.
2. على الكمبيوتر (على نفس شبكة الشاشة): دبل كليك على `scripts\setup-new-tv.bat`.
   - هيسألك على اسم للشاشة (زي `bedroom`) وعلى الـ IP، ولما يطلب الـ Passphrase اكتبه.
   - بعدها بيثبّت التطبيق، وبيضيف الشاشة للتجديد اليومي على GitHub لوحده.

**`scripts\sync-tokens.bat`:** بيجمع الـ tokens من كل شاشاتك ويحدّث GitHub.
- **استخدمه لو قفلت Developer Mode على شاشة وفتحته تاني،** لأن الـ token بتاعها بيتغير.
- **ولو فيه شاشة مقفولة ومالهاش token محفوظ،** مش هيرفع حاجة، وهيقولك تفتحها الأول. كده عمره ما هيشيل شاشة من التجديد بالغلط.

**عشان تحدّث شاشة معينة بعد كده:** `scripts\install.bat bedroom`. ولو مااكتبتش اسم، السكريبت بيستخدم الشاشة الأولى `tv`.

**من غير أوامر خالص:** حمّل برنامج **webOS Dev Manager** (https://github.com/webosbrew/dev-manager-desktop/releases):
1. دوس **Add Device**، واكتب الـ IP والـ Passphrase.
2. اسحب ملف `.ipk` جوه البرنامج.

ملف الـ `.ipk` بتلاقيه في فولدر `dist` بعد أي تشغيل لـ `install.bat`، أو في صفحة **Releases** على GitHub بعد ما تفعّل الملفات اللي في القسم اللي جاي.

## تفعيل ملفات GitHub الإضافية (مرة واحدة)

في فولدر `extras/workflows` فيه ملفين جاهزين:
- **`build-ipk.yml`**: بيعمل ملف `.ipk` أوتوماتيك مع كل تحديث، وبيحطه في صفحة **Releases**.
- **`extend-devmode.yml`**: بيجدد Developer Mode كل يوم **لكل الشاشات** اللي في `LG_DEVMODE_TOKENS`، كل token في سطر. ولسه بيقرا كمان الـ secret القديم `LG_DEVMODE_TOKEN`. وكمان بيعمل تعديل صغير كل فترة، عشان GitHub مايوقفش المهام المجدولة في الـ repo العام بعد 60 يوم من غير نشاط.

**عشان تفعّلهم من موقع GitHub:**
1. افتح الملف، ودوس على ✏️ (Edit).
2. غيّر مكانه في خانة الاسم من `extras/workflows/` لـ `.github/workflows/`.
3. دوس **Commit changes**.

بالنسبة لـ `extend-devmode.yml`: الملف القديم اللي بنفس الاسم في `.github/workflows` امسحه الأول أو عدّل محتواه.

## التحديث عن بعد (من غير كمبيوتر)

من نسخة 1.2.0، التطبيق بيحدّث نفسه من النت لوحده:
- كل ما يفتح، بيدوّر في الخلفية على نسخة أجدد في الملف `update/bundle.json` في الـ repo ده (لازم الـ repo يكون Public).
- لو لقى، بينزّلها وتشتغل من المرة الجاية. ولو عايزها على طول، روح على **الإعدادات ← دوّر على تحديث**.
- **حماية:** لو نسخة جديدة طلع فيها مشكلة ومنعت التطبيق يفتح، بيرجع لوحده للنسخة المتثبتة على الشاشة.

**إزاي تنشر تحديث:**
1. زوّد رقم النسخة في `app/js/version.js` وفي `app/appinfo.json`، ولازم الاتنين يبقوا نفس الرقم.
2. اعمل ملف التحديث:
   ```
   node scripts/build-bundle.js
   ```
3. ارفع التعديلات على GitHub، والملف `update/bundle.json` معاهم.

> التحديث عن بعد بيغيّر الشكل والكود بس. لو اتغيرت الأيقونة أو `appinfo.json` أو مكتبة mpegts.js، لازم تثبّت بـ `install.bat` تاني.

## تثبيت التطبيق على شاشة سامسونج

نفس التطبيق بالظبط، بنفس الشكل والمميزات والاشتراكات والتحديث الأوتوماتيك. وفي سامسونج **مفيش مدة 50 ساعة**.

**على الكمبيوتر (مرة واحدة):**
1. نزّل **Tizen Studio** من موقع سامسونج للمطوّرين (Samsung Developers ← Smart TV ← Tizen Studio) وثبّته.
2. افتح **Package Manager** (بييجي مع Tizen Studio)، ومن تبويب **Extension SDK** ثبّت **TV Extensions** و **Samsung Certificate Extension**.

**على الشاشة (مرة واحدة لكل شاشة):**
1. افتح **Apps**، واكتب بالريموت `1 2 3 4 5`.
2. شغّل **Developer mode**، واكتب **IP الكمبيوتر**، ودوس OK.
3. اقفل الشاشة وافتحها تاني (دوس على زرار الباور مطوّل).

**ربط الشاشة وشهادة التوقيع (مرة واحدة):**
1. في Tizen Studio افتح **Device Manager**، وبعدين **Remote Device Manager**. دوس **+**، واكتب IP الشاشة، وبعدين **Connect**.
2. افتح **Tools ← Certificate Manager**، ودوس **+**، واختار **Samsung** وبعدين **TV**.
3. سمّي البروفايل **`nexlify`** بالظبط.
4. سجّل دخول بحساب Samsung.
5. في خطوة **Distributor**، اتأكد إن رقم الشاشة (**DUID**) متضاف. بيتضاف لوحده لو الشاشة متوصلة.

**التثبيت:**
- دبل كليك على `scripts\samsung-install.bat` واكتب IP الشاشة.
- أو من Command Prompt:
  ```
  scripts\samsung-install.bat 192.168.1.20
  ```

**لما تضيف شاشة سامسونج جديدة:**
1. افتح **Certificate Manager**.
2. عدّل البروفايل `nexlify`، وضيف DUID الشاشة الجديدة.
3. شغّل `samsung-install.bat`.

> التطبيق بيشتغل أحسن على شاشات سامسونج من **2020 وأحدث**. الموديلات الأقدم متصفحها قديم، وممكن بعض المسافات في الشكل تبان مختلفة.

## تحديث المشروع على الكمبيوتر أوتوماتيك

لو عامل Clone للمشروع (بـ GitHub Desktop مثلاً) ومتثبت عندك **Git for Windows** (https://git-scm.com/download/win)، فـ `install.bat` بيجيب آخر نسخة من GitHub لوحده قبل ما يثبّت.
- يعني دبل كليك واحدة بتحدّث وبتثبّت.
- أول مرة ممكن يطلب منك تسجّل دخول GitHub من المتصفح، مرة واحدة بس.

## تحديث التطبيق لنسخة جديدة

1. نزّل آخر نسخة من GitHub: **Code ← Download ZIP**، وفكّها مكان القديمة. ولو عامل clone، اعمل `git pull`.
2. اتأكد إن الشاشة مفتوحة وإن Developer Mode لسه شغال.
3. شغّل:
   ```
   scripts\install.bat
   ```
التطبيق هيتحدّث مكان القديم، وبيانات الدخول والمفضلة هتفضل زي ما هي.

## حل المشاكل

- **القناة مش شغالة:** روح على **الإعدادات ← صيغة البث المباشر**، وغيّرها لـ TS. وعلى العموم، التطبيق بيجرّب TS لوحده لو HLS فشل.
- **بيقولك "تعذّر الاتصال بالسيرفر":** اتأكد إن عنوان السيرفر مكتوب كامل بالبورت، مثلاً `http://example.com:8080`.
- **عايز تغيّر الاشتراك:** روح على **الإعدادات ← تسجيل الخروج**.
- **التحديثات:** لو عدّلت في الكود، شغّل `scripts\install.bat` تاني.

```
scripts/

.github/workflows/

```
