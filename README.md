# Nexlify: IPTV Player لشاشات LG (webOS)

تطبيق مجاني لتشغيل اشتراك Xtream على شاشات LG، بالعربي والإنجليزي.

- **قنوات** مع البرنامج اللي شغال دلوقتي واللي بعده، وقسم للقنوات اللي اتفرجت عليها مؤخراً.
- **أفلام** فيها صفحة تفاصيل (القصة، التقييم، المدة، الممثلين)، وتقدر تكمّل من حيث وقفت.
- **مسلسلات** بالمواسم والحلقات، والحلقة اللي بعدها بتشتغل لوحدها.
- **المفضلة والبحث**، والتحكم كامل بالريموت.
- **بيانات الاشتراك** بتتكتب على الشاشة مرة واحدة، ومابتتبعتش لأي حد غير سيرفر الاشتراك.
- **اللغة** بتتغير من **الإعدادات ← اللغة**، أو من زرار English/العربية في شاشة الدخول.

---

## أولاً: تجهيز الشاشة (مرة واحدة)

1. اعمل حساب مجاني على https://webostv.developer.lge.com (Sign In ← Create Account).
2. على الشاشة: افتح **LG Content Store**، ودوّر على **Developer Mode** وثبّته.
3. افتح تطبيق Developer Mode، وادخل بحساب LG Developer.
4. فعّل **Dev Mode Status**، والشاشة هتعمل ريستارت.
5. افتح Developer Mode تاني، وفعّل **Key Server**.
6. اكتب عندك **الـ IP** و**الـ Passphrase** اللي ظاهرين في التطبيق.

## ثانياً: تجهيز الكمبيوتر (ويندوز، مرة واحدة)

1. نزّل **Node.js LTS** من https://nodejs.org وثبّته.
2. افتح **Command Prompt** واكتب:
   ```
   npm install -g @webos-tools/cli
   ```
3. ضيف الشاشة باسم `tv`. حط الـ IP بتاع شاشتك مكان `192.168.1.50`:
   ```
   ares-setup-device -a tv -i "host=192.168.1.50" -i "port=9922" -i "username=prisoner"
   ```
4. اربط الكمبيوتر بالشاشة، ولما يسألك اكتب الـ Passphrase:
   ```
   ares-novacom --device tv --getkey
   ```
5. اتأكد إن الربط شغال:
   ```
   ares-device --device tv --system-info
   ```

> الكمبيوتر والشاشة لازم يكونوا على نفس الواي فاي.

## ثالثاً: تثبيت التطبيق

من فولدر المشروع، دوس دبل كليك على `scripts\install.bat`، أو شغّله من Command Prompt:
```
scripts\install.bat
```
السكريبت بيعمل الآتي:
- بيحمّل مكتبة تشغيل البث (mpegts.js).
- بيعمل باكدج للتطبيق ويثبّته على الشاشة ويفتحه.

بعد كده هتلاقي **IPTV Player** في قايمة التطبيقات على الشاشة.

## رابعاً: التجديد الأوتوماتيك لـ Developer Mode

وضع المطوّر بيخلص بعد 50 ساعة، ولما يخلص الشاشة بتمسح التطبيق. ملف GitHub في المشروع بيجدده كل يوم لوحده.

1. ارفع المشروع على GitHub كـ repo **Private**.
   - الـ repo لازم يكون Private، لأن GitHub بيوقف المهام المجدولة في الـ repos العامة لو فضلت 60 يوم من غير أي تعديل.
2. هات الـ token من الشاشة بالأمر ده:
   ```
   scripts\get-devmode-token.bat
   ```
   هيطبعلك نص طويل، وده هو الـ token.
3. على GitHub افتح الـ repo، وروح على **Settings ← Secrets and variables ← Actions ← New repository secret**:
   - Name: `LG_DEVMODE_TOKEN`
   - Secret: الـ token اللي طلع في الخطوة اللي فاتت
4. روح على تبويب **Actions**، واختار **Extend LG Developer Mode**، ودوس **Run workflow**.
5. افتح تطبيق Developer Mode على الشاشة، واتأكد إن العداد رجع لحوالي 50 ساعة.

> لو التشغيل فشل (هيوصلك إيميل من GitHub)، فغالباً الـ token اتغيّر. ده بيحصل لو قفلت وضع المطوّر وفتحته تاني. الحل إنك تعيد الخطوتين 2 و3.
>
> ولو الشاشة مسحت التطبيق في أي وقت، شغّل `scripts\install.bat` تاني وهيرجع.

## تحديث التطبيق لنسخة جديدة

1. نزّل آخر نسخة من GitHub: **Code ← Download ZIP**، وفكّها مكان القديمة. ولو عامل clone، اعمل `git pull`.
2. اتأكد إن الشاشة مفتوحة وإن Developer Mode لسه شغال.
3. شغّل:
   ```
   scripts\install.bat
   ```
التطبيق هيتحدّث مكان القديم، وبيانات الدخول والمفضلة هتفضل زي ما هي.

| الأرقام | — | تروح لرقم القناة | — |
| ⏩ ⏪ | — | — | تقدّم أو ترجع دقيقة |
| رجوع | ترجع للخلف، ومرتين تخرج من التطبيق | تقفل البث | تقفل الفيديو وتحفظ المكان اللي وقفت عنده |

## حل المشاكل

- **القناة مش شغالة:** روح على **الإعدادات ← صيغة البث المباشر**، وغيّرها لـ TS. وعلى العموم، التطبيق بيجرّب TS لوحده لو HLS فشل.
- **بيقولك "تعذّر الاتصال بالسيرفر":** اتأكد إن عنوان السيرفر مكتوب كامل بالبورت، مثلاً `http://example.com:8080`.
- **عايز تغيّر الاشتراك:** روح على **الإعدادات ← تسجيل الخروج**.
- **التحديثات:** لو عدّلت في الكود، شغّل `scripts\install.bat` تاني.
